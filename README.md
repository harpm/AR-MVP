# AR-MVP - Augmented Reality Sample Application

## Overview

Welcome to AR-MVP, an innovative augmented reality (AR) application developed using Unity, designed to revolutionize the way consumers shop online! This application showcases the incredible potential of AR in mobile applications, specifically tailored for e-commerce. With support for both Android and iOS platforms, ARCommerce allows users to visualize furniture and other products in their own space before making a purchase. Experience the future of shopping today!

## Features

- **Cross-Platform Compatibility**: Built to run seamlessly on both Android and iOS devices, ensuring a wide reach for all users.

- **Immersive Product Visualization**: Users can view furniture and other items in real-time within their environment, helping them make informed purchasing decisions.

- **Color-Coded Connection Points**: Easily identify key features of products with color coding, enhancing user experience and interaction.

- **User-Friendly Interface**: Designed with simplicity in mind, making it easy for anyone to navigate through the app and utilize its features.

## Used techs
- **Unity**
- **ARCore(Fore Android)**
- **ARKit(For IOS)**
- **Finger Gesture unity Package**
